# Roadmap
# v0.7 — Front Foundation

**Status:** Planning

## Goal

Introduce the first user-facing interface for MOA outside EasyAdmin.

This version will establish the HTML, Twig and CSS foundations of the application and provide the first functional document browsing screens.

## Completion Criteria

v0.7 can be considered complete when:

- A shared Twig layout exists.
- Header, navigation and footer are implemented.
- A simple responsive visual identity is established.
- Bootstrap is integrated and documented.
- Front-end HTML and CSS conventions are defined.
- A user-facing home page exists.
- A user-facing document list exists.
- A basic document detail page exists.
- The interface works correctly on desktop and mobile.
