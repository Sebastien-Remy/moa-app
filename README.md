# MOA

MOA is an open-source, document-centered business management application for small companies.

The document is the central object of the application.

Around each document, MOA helps manage:

- financial categories
- payments
- bank reconciliation
- analytics
- dashboards

MOA is **not** an accounting software.

Its goal is to organize business documents, monitor expenses and revenues, and prepare data for accountants.

## Technology

- Symfony 8
- PHP 8.4
- PostgreSQL
- Docker Compose
